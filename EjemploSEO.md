
1. SEO Técnico (La base estructural)

Garantiza que los motores de búsqueda puedan encontrar, rastrear e indexar tu sitio web sin problemas.
• Archivo robots.txt: Configura este archivo en la raíz de tu web para guiar a los bots de Google sobre qué páginas indexar y cuáles ignorar.
• Mapa del sitio (sitemap.xml): Genera y envía el mapa del sitio a Google Search Console para facilitar el rastreo de tus URLs.
• Protocolo HTTPS: Asegura tu sitio con un certificado SSL válido; la seguridad es un factor de clasificación directo.
• Velocidad de carga (Core Web Vitals): Optimiza el rendimiento de tu web. Revisa métricas como el LCP (carga principal), INP (interactividad) y CLS (estabilidad visual) usando Google PageSpeed Insights.
• Optimización móvil: Aplica un diseño completamente responsivo. Google utiliza la indexación Mobile-First (prioriza la versión móvil para el ranking).
• Estructura de URLs: Limpia tus enlaces para que sean "amigables" (ej: ://web.com en lugar de ://web.com).
• Etiquetas Canónicas (rel="canonical"): Implementa estas etiquetas para evitar problemas de contenido duplicado si una misma página es accesible desde distintas URLs.
• Código de estado HTTP: Monitorea y repara enlaces rotos (errores 404) y configura correctamente las redirecciones 301 (permanentes).

2. SEO On-Page (Optimización del contenido)

Asegura que el contenido de cada página esté optimizado para las palabras clave que busca tu audiencia.
• Etiqueta de título (<title>): Crea títulos únicos para cada página de menos de 60 caracteres, incluyendo la palabra clave principal al inicio.
• Meta descripción (<meta name="description">): Escribe resúmenes atractivos de menos de 155 caracteres que inviten al usuario a hacer clic (mejora el CTR).
• Jerarquía de encabezados (H1, H2, H3): Usa un único H1 por página para el título principal. Organiza el resto del contenido con subtítulos H2 y H3 de forma lógica.
• Optimización de imágenes:
	• Reduce el peso de los archivos (usa formatos modernos como WebP).
	• Llena siempre el atributo Alt text (texto alternativo) describiendo la imagen con palabras clave de forma natural.
• Palabras clave y semántica: Distribuye tu palabra clave principal en el primer párrafo, los encabezados y el texto, apoyándote en sinónimos y términos relacionados (LSI) para evitar el keyword stuffing.
• Enlaces internos: Conecta tus páginas entre sí usando textos de anclaje (anchor text) descriptivos para repartir la autoridad del sitio.
• Enlaces externos: Enlaza a fuentes externas de alta autoridad y confianza cuando sea necesario para respaldar tu información.
• Datos estructurados (Schema Markup): Implementa fragmentos de código Schema para ayudar a Google a entender si tu web es un artículo, un producto, una receta o un negocio local, permitiendo aparecer como "resultado enriquecido".

3. SEO Off-Page (Autoridad y reputación)

Acciones fuera de tu propio sitio web para demostrarle a Google que tu página es una autoridad en su sector.
• Estrategia de Linkbuilding: Consigue enlaces entrantes (backlinks) desde sitios web relevantes y de alta autoridad en tu nicho.
• Enlaces de calidad sobre cantidad: Prioriza que los enlaces sean naturales, de sitios limpios (sin spam) y que aporten tráfico real.
• Menciones de marca: Fomenta que hablen de tu marca en foros, blogs, periódicos digitales y redes sociales, incluso si no incluyen un enlace directo.

4. SEO Local (Si aplica a tu negocio)

Esencial si ofreces servicios o productos en una ubicación geográfica específica.
• Perfil de Empresa en Google (Google My Business): Reclama, verifica y optimiza tu perfil con horarios, fotos, dirección exacta y la categoría de negocio correcta.
• Consistencia NAP: Asegúrate de que el Nombre, la Dirección y el Teléfono (Name, Address, Phone) sean exactamente iguales en tu web, redes sociales y directorios locales.
• Reseñas de clientes: Incentiva activamente a tus usuarios a dejar reseñas positivas y responde a cada una de ellas de forma profesional.
